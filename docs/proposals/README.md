# Proposals Documentation

- **Owner**: Auriora Team
- **Status**: Approved
- **Created Date**: 27-10-2023
- **Last Updated**: 27-10-2023

## 1. Purpose

**When to use this template**: This folder is for documents that suggest a change or course of action. Proposals can range from high-level strategic suggestions
to detailed technical plans. Use these documents to build consensus and get buy-in before committing to significant work.
**Location**: `docs/proposals/`

## 2. What Belongs Here?

- Initial ideas for new features or systems.
- Suggestions for process improvements.
- Technical proposals requiring review and approval.

## 3. What Does NOT Belong Here?

- Approved implementation plans; use an active spec.
- Formal architectural decisions (see `../2-architecture/`).
- Daily updates or change logs; use Git commits and pull requests.
